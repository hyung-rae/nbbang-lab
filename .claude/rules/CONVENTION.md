# CONVENTION.md — nbbang-lab

> 이 파일에는 **"이렇게 써라"(규범)** 만 둔다.
> **"이렇게 되어 있다"(구조·명령어·함정 설명)** 는 `CLAUDE.md`(루트 + 디렉터리별)가 정본이다 — 여기에 다시 쓰지 않고 링크한다.
> 충돌 시 우선순위: `.claude/commands/git/commit.md` > **이 파일** > `CLAUDE.md` > `.claude/review-rules.md`

## 커밋 · 브랜치

- gitmoji 컨벤션 (`✨ Feat:`, `🐛 Fix:`, `🚚 Move:` …) — 형식·절차·전체 목록은 `.claude/commands/git/commit.md`(레포 내 정본)
- 제목은 간결하게, 본문은 한국어로 변경 이유·내용·영향 범위 서술
- 브랜치 흐름: `<type>/<설명>` 작업 브랜치 → `main`. `main` 에 직접 커밋하지 않는다(첫 커밋 예외)
- 커밋·push는 **사용자가 요청할 때만 시작한다** (`review-rules.md` W-001)

## 코드

- **새 함수를 만들기 전에 기존에 비슷한 함수가 있는지 먼저 확인한다** (중복 금지).
- **주변 체계를 따른다.** 스타일·상태관리·데이터 접근 방식이 정해지면 그 방식을 쓰고, 정해지기 전에는 임의로 새 체계를 들이지 않고 먼저 제안한다.
- side effect가 우려되는 수정(데이터 스키마·저장 형식·권한 변경 등)은 **하기 전에 사용자 확인**을 받는다.
- 포맷터·린터를 레포 전체에 돌리지 않는다(대량 diff 유발). 변경 범위에만 적용한다.

## 도메인 (명세: dev-wiki `여행 가계부 작업 계획.md`)

- **금액은 원 단위 정수로만 다룬다.** 부동소수 연산으로 나누지 않는다 — 나머지 원은 명세의 `splitEven` 규칙(앞사람부터 1원씩)을 따른다.
- **정산 순서를 바꾸지 않는다**: 지출별 1원 단위 N빵 → 사람별 잔액 → 100원 단위 정리(끝전은 덤탱이 쓸 사람) → 최소 송금.
- 정산 계산은 화면 코드와 분리된 **순수 함수**로 두고 테스트로 고정한다 — 금액이 1원만 틀려도 친구 사이 신뢰 문제가 된다.
- **모바일(폰 폭) 기준으로 설계한다.** 입력창 글자 16px(iOS 확대 방지), 한글 `word-break: keep-all`, 숫자 `tabular-nums`.

## 화면 · 데이터

- **날짜·선택 입력은 shadcn 기반 부품(`src/components/form/`)을 쓴다.** 브라우저 기본 `<input type="date">`·`<select>` 는 쓰지 않는다 (사용자 지시 2026-10-06).
- **폼은 다른 화면의 변경(실시간 갱신)으로 props 가 바뀌어도 남의 변경을 덮어쓰거나 지워진 대상을 되살리지 않게 만든다.** 패턴은 [`src/components/CLAUDE.md`](../../src/components/CLAUDE.md).
- **개수 제한·다음 순서 번호처럼 "읽고 → 계산 → 넣기"가 필요한 변경은 DB 함수로 원자적으로 한다.** 패턴은 [`supabase/CLAUDE.md`](../../supabase/CLAUDE.md).
- 새 DB 객체(테이블·함수·뷰)는 같은 마이그레이션에서 `anon`·`authenticated` 권한을 회수하고 스키마 테스트에 권한 케이스를 추가한다.
